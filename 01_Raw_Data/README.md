# Raw Data / Source Reference

The project was developed from TRAI Performance Monitoring Report (PMR)
source material covering **July 2025 to July 2026**.

The source reports were used for extraction, reconciliation, and
validation. To keep the public repository focused and avoid unnecessary
duplication of publisher-owned source documents, this folder can contain
this source-reference note instead of all raw PDFs.

## Data Preparation

Relevant tables were extracted and consolidated using **Microsoft Excel
and Power Query**. Source pages were manually rechecked where PDF table
detection omitted records or split tables inconsistently.

Missing or unavailable source KPI values were preserved as blanks/nulls
rather than replaced with estimated values.

## Attribution

Source data/report ownership remains with the original publisher. This
repository contains the analytical work, transformations, SQL,
dashboards, documentation, and portfolio outputs created for the
project.
